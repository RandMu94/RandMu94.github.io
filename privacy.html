JobBot Privacy Policy

Last updated: 10 November 2026

JobBot is a private job-search tool used by a single person on their own computer. This policy explains what Google user data it accesses, how it is used, and where it goes.

Data JobBot accesses

JobBot asks for two Gmail permissions and no others:

  • Read email (gmail.readonly): to read job-alert emails the user has labelled for JobBot, and to search the user's Sent folder for earlier job applications.
  • Send email (gmail.send): to send a job application, only after the user has reviewed it and clicked Send.

JobBot does not change, delete or label existing emails, and does not access contacts, calendar, Drive or any other Google service.

Where the data is stored

Everything JobBot keeps is stored only on the user's own computer: job details in a local database, and the Gmail sign-in token in the operating system's keychain. There is no JobBot server and no cloud database.

Who the data is shared with

To score job postings and draft CVs and cover letters, JobBot sends the text of job postings, including job-alert email content, and the user's CV information to the Anthropic API (Claude). See Anthropic's privacy policy. The data is not shared with anyone else, not sold, and not used for advertising.

Google API Services User Data Policy

JobBot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can revoke JobBot's access to Gmail at any time at myaccount.google.com/permissions. Deleting the JobBot folder from the computer removes all data it stored.
