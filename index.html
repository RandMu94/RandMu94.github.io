JobBot

A private job-search assistant.

JobBot is a personal tool used by one person for their own job search. It is not a public service, and no one can sign up for it.

It runs only on the user's own computer. With the user's permission it connects to their Gmail account to:

  • read job-alert emails (for example LinkedIn job alerts) that the user has labelled for JobBot,
  • read the user's sent applications, so the same job is not applied to twice,
  • send job applications, but only after the user has reviewed them and clicked Send.

See the privacy policy for exactly what data is used and where it goes.
